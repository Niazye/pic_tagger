## 范围
  - 包含（In-Scope）：
      - 导入外部图片/文件夹（仅索引，不复制）。
      - 自定义任意字符串标签（增加/删除/重命名）。
      - 编辑长文本描述。
      - 按标签组合（交集/并集）和关键词搜索。
      - 图片预览（缩略图与原始大图查看）。
      - 文件变动检测（外部文件被删除或移动时的标记与重连）。
  - 不包含（Out-of-Scope）：
    - 内置图片编辑功能（调色、裁剪）。
    - 云同步或云端备份。

## 功能需求

### 1. 图片导入模块

   |功能|优先级|说明|
   |---|---|---|
   |添加文件|P0|用户可以选择单个图片文件进行导入，程序会将图片索引添加到数据库中，支持批量导入。|
   |添加文件夹|P0|用户可以选择一个文件夹进行导入，程序会递归遍历文件夹中的所有图片文件，并将其索引添加到数据库中。|

## 5. 非功能需求

### 1. 性能
- **响应时间**：在 1000 张图片的数据库中，搜索操作的响应时间应小于 500ms。
- 启动时间：应用程序启动时间应小于 3 秒。
- **内存占用**：在处理 1000 张图片时，应用程序的内存占用应小于 200MB。
### 2. 数据库
- **数据库选择**：使用 SQLite 作为本地数据库，确保数据的持久化和快速访问。
### 3. 数据保持
- **数据持久化**：所有图片索引、标签和用户设置应在应用程序关闭后保持不变，数据保存至程序文件夹。
- **数据备份**：提供手动备份和恢复功能，允许用户将数据库导出为文件，并在需要时导入恢复，卸载时询问用户是否需要备份数据。
- **绿色**：数据全部保存在程序文件夹内，不用注册表或系统目录，以防在电脑里拉屎。
### 4. 兼容
- **utf8**: 所有文本数据应使用 UTF-8 编码，确保多语言支持。
- **图片格式**：支持所有图片格式，标签功能和图片本身无关，不可用图片使用默认缩略图，不影响标签。

### 5.2 数据库设计约束（核心变更）
- **强制使用 SQLite**。
- **必须建立的索引（Index）**：
  - `categories(name)` (唯一索引)
  - `tags(category_id, name)` (**复合唯一索引**，保证同分类下标签不重名)
  - `image_tags(image_id, tag_id)` (复合索引，加速关联查询)
  - `images(file_hash)` (普通索引)

### 5.3 数据安全
- 纯本地运行，无任何云端上传。

## 7. 用户界面布局（UI Layout）—— 核心设计

整体布局采用 **“上 + 中 + 右”** 三块结构（无左侧边栏）：

| 区域 | 位置 | 内容 | 类比 Windows 资源管理器 |
| :--- | :--- | :--- | :--- |
| **顶部工具栏** | 窗口上方 | 路径/筛选条件显示、视图切换按钮（大/中/小图标、详细信息）、搜索框。 | 地址栏 + 布局切换按钮 + 搜索框 |
| **中间文件列表** | 窗口中央（占据 70% 宽度） | 图片/文件夹的陈列区。支持**四种视图模式**（下文详述）。 | 文件列表主区域 |
| **右侧详情面板** | 窗口右侧（占据 30% 宽度） | 固定显示当前选中图片的：大预览图、**分类-标签编辑区**、描述输入框、文件元数据（路径、尺寸、大小）。 | 预览窗格（但功能大幅增强） |

## 8. 中间文件列表视图（核心交互）

### 1 通用交互（所有视图通用）
- **单击**：选中图片，右侧详情面板同步刷新。
- **Ctrl + 单击**：多选（逐个追加）。
- **Shift + 单击**：连续区间多选。
- **右键菜单**：提供“删除索引”、“复制路径”、“在文件管理器中定位”等操作。

### 2 视图模式详细说明

| 视图模式 | 展示形式 | **标签信息展示策略** | 分组/排序 |
| :--- | :--- | :--- | :--- |
| **超大/大图标** | 图片缩略图（256x256 / 128x128）居中排列。 | 缩略图**下方**显示 1-2 行标签分组（例如：<br>`👤作者：米山舞`<br>`🎬作品：原神`）。若标签过多，显示 `...+N`。 | 不支持列头排序，右键菜单可分组依据（如按“作者”分类分组，但逻辑复杂，V1暂不强制）。 |
| **中/小图标** | 缩略图（64x64 / 48x48）平铺。 | 缩略图**右侧**或**下方**紧凑显示最多 3 个核心标签（优先展示用户“置顶”的分类）。 | 同大图标。 |
| **详细信息（列表）** | **表格形式**：行高固定，列可拖动调整宽度。 | **独立的“标签”列**（位于“大小”列与“修改日期”列之间）。<br>该列内容格式为：`[分类1]：标签A、标签B；[分类2]：标签C`。<br>**用户可通过点击该列头，对图片按标签字符串进行字母序排序**（非常实用）。 | **支持点击任意列头排序**（名称、日期、大小、**标签**）。<br>**支持右键列头**，勾选显示或隐藏“标签”列。 |
| **内容（列表）** | 类似详细信息，但不显示缩略图，仅显示文件名和图标。 | 同“详细信息”视图，保留“标签”列。 | 同“详细信息”视图。 |

**细节说明（详细信息视图的“标签”列）：**
- 若图片无任何标签，该列显示为灰色文字 `（无标签）`。
- 若标签内容过长，列宽不足时，鼠标悬停显示完整内容的 Tooltip（气泡提示）。
- 分类名以**不同颜色**的方括号区分（颜色取自该分类在后台设置的颜色）。

## 9. 右侧详情面板（详情面板）

该面板随中间列表的选中项实时刷新。若选中**多张图片**，则面板进入“批量编辑模式”。

| 功能区块 | 详细说明 |
| :--- | :--- |
| **缩略图预览** | 显示当前选中图片的大尺寸预览（适配面板宽度）。若多选，显示“已选中 X 张图片”。 |
| **文件基础信息** | 只读显示：文件路径、文件大小、图片尺寸（宽x高）、文件修改时间、导入时间。 |
| **描述编辑区** | 多行文本输入框，支持换行。用于记录长文本备注。 |
| **标签编辑区（核心）** | **操作方式**：<br>1. **选择分类**：下拉选择框，列出所有已创建分类（含“未分类”）。<br>2. **输入/选择标签**：文本框，输入字符时自动联想**当前选定分类下**已有标签。<br>3. **点击“添加”或按回车**：立即为该图片挂载该标签。<br>**已挂载标签展示**：以“药丸（Pill）”样式展示所有已挂载标签，格式为 `[分类颜色条] 分类名：标签名 [×]`。点击 `[×]` 单独移除该标签。<br>**多选模式**：在此处添加或移除标签，将**同时作用于所有选中的图片**（批量操作）。 |

## 8. 异常与边界情况处理（新增）

| 场景 | 处理逻辑 |
| :--- | :--- |
| **用户试图在“作者”分类下创建已存在的标签“米山舞”** | 输入框变红，Tooltip提示“该分类下已存在此标签”，禁止创建。 |
| **用户删除一个非空的分类** | 弹窗二选一：<br>1. “将此分类下的所有标签移至‘未分类’”（保留标签文字和图片关联）。<br>2. “彻底删除该分类及所有标签”（级联删除 `tags` 和 `image_tags` 中相关记录）。<br>**默认分类“未分类”不可删除、不可重命名**。 |
| **用户重命名分类** | 全库搜索该分类ID，将所有图片卡片上的展示文字批量更新（数据库只改 `categories.name` 一条记录，UI实时刷新即可）。 |
| **一张图拥有同一分类下过多标签（如100个）** | UI展示时限制该分类只显示前5个标签，后跟 `...+还有95个`，鼠标悬停显示全部气泡。 |
