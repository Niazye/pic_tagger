## 🚀 安装与运行

### 环境要求
- **Python 3.12+**
- **大概**支持 Windows / macOS / Linux

### 安装步骤

```bash
# 1. 克隆或下载项目
git clone <仓库地址>
cd pic_tagger

# 2. 创建虚拟环境（推荐）
python -m venv .venv

# 3. 激活虚拟环境
# Windows (PowerShell):
.venv\Scripts\Activate.ps1
# macOS / Linux:
source .venv/bin/activate

# 4. 安装依赖
pip install -r requirements.txt

# 5. 启动程序
python -m src.main
```

### 打包为可执行文件（可选）

项目已配置 PyInstaller，可打包为独立可执行程序：

```bash
pyinstaller main.spec
```

打包后的程序位于 `dist/` 目录，可直接双击运行，无需安装 Python。

## 📖 使用指南

### 导入图片
1. 点击工具栏的 **"导入"** 按钮。
2. 选择单个或多个图片文件（或选择文件夹）。
3. 程序自动建立索引并生成缩略图。

### 添加标签
1. 在中间列表**单击**选中一张图片（或 Ctrl/Shift 多选）。
2. 在右侧详情面板的**标签编辑区**：
   - 选择分类（如"作者"）。
   - 输入标签名（自动联想已有标签）。
   - 点击"添加"或按回车。
3. 已挂载的标签以"药丸"样式展示，点击 `×` 可移除。

### 搜索图片
- 在顶部**搜索框**输入关键词，列表实时筛选。
- 清空搜索框即可恢复显示全部图片。

### 切换视图
- 点击工具栏的 **"超大 / 大 / 中 / 小 / 详情列表"** 按钮切换视图模式。

### 处理丢失的文件
1. 点击 **"刷新"** 按钮检测丢失文件。
2. 丢失的图片会**置灰**并显示 ⚠ 警告标记。
3. 右键丢失的图片 → **"重新连接"**，选择新的文件路径即可恢复。

### 备份与恢复
- **备份**：点击 **"导出"** 按钮，选择保存位置，生成 `.db` 备份文件。
- **恢复**：点击 **"恢复"** 按钮，选择备份文件，确认后覆盖当前数据。

> ⚠️ 恢复备份会**覆盖当前所有数据**，请谨慎操作。

## 📁 数据存储位置

所有数据保存在程序文件夹内（"绿色"原则，不污染系统目录）：

| 内容 | 位置 |
| :--- | :--- |
| 数据库（图片索引、标签） | `data.db` |
| 缩略图缓存 | `cache/thumbnails/` |
| 日志 | `logs/` |

> 备份时建议同时备份 `data.db` 和 `cache/` 目录，以保留缩略图。

---

## 🧩 支持的图片格式

支持常见图片格式：`.jpg`、`.jpeg`、`.png`、`.bmp`、`.gif`、`.tiff`、`.webp`。

> 即使图片文件不可用，标签功能依然正常，不可用图片会显示默认缩略图。
